### 5.1 正式版

- 智谱 Key 使用 Windows 凭据加密保存在本机，也支持 `ZHIPU_API_KEY` 环境变量；截图先识别，再交给当前 Claude/DeepSeek 会话继续处理。

### 5.0 正式版

- 每次启动停留在“今天想做点什么”首页，不再自动进入上次对话；三个功能卡片与“新建项目”入口同时保留。
- 新增右侧任务时间线：按每次用户要求生成主题、时间与状态节点，点击即可跳回当时的对话位置。
- 新建项目可留空名称，命名优先级为“手动名称 → 本地项目元数据 → 首个任务主题 → 文件夹名”；手动改名后永久优先。
- “新建项目”只创建项目空间，不会偷偷复用上一个目录创建会话；项目内会话、未归类会话分开显示，项目可以折叠或展开。
- 默认权限模式和响应强度改为主题化卡片，不再弹出与项目风格不一致的 Windows 原生下拉菜单。
- 模型选择器改为“供应商大类 → 具体模型”，Claude、DeepSeek、OpenAI / GPT / Codex 等默认折叠，搜索时直接显示匹配结果。
- 首页会直接显示 Claude 实际使用的项目名称和工作目录；顶部栏与输入台显示项目名，悬停可查看完整目录，防止界面项目与运行目录不一致。
- 输入台支持屏幕/窗口截图，快捷键为 `Ctrl + Shift + 4`；截图会先预览，再直接附加到消息发送。
- 截图识别默认使用国内智谱 `glm-4v-flash`：视觉模型先返回截图事实，随后由当前会话模型继续处理原任务；首次点击截图会提示输入智谱 API Key。

## 功能

- 原生 Windows 桌面窗口，无需启动网页服务器。
- 按项目归档会话；项目可自动识别名称，项目和会话也都可手动重命名，每个项目可单独新建多段对话。
- 选择项目文件夹后直接与 Claude Code 对话。
- 会话历史、任务时间线、Markdown、代码块复制、思考过程与工具调用展示。
- AI 工作时仍可继续输入补充要求，排队后自动依次执行；也可停止当前任务。
- 用户消息和 AI 回答均可一键复制，输入区支持主题化右键复制、粘贴和全选。
- 在输入台按供应商展开、搜索并切换应用内置模型目录，也可使用自定义模型 ID、推理强度和权限模式；未知的新模型会自动匹配供应商图标或回退到通用图标。
- 根据 Claude Code 返回的 usage 数据显示上下文占用。
- 沿用本机 Claude Code 配置，但不依赖 CC Switch 或其他模型切换器；模型目录、品牌图标和视觉设置由本应用维护。
- 不读取第三方切换器数据库中的密钥，也不会在程序或仓库中嵌入密钥；余额查询会按上一条说明读取当前 Claude 配置并直连 DeepSeek 官方 HTTPS 接口。

## 运行要求

- Windows 10/11 64 位。
- 已安装 Claude Code CLI，并已完成登录或 API/供应商配置。
- 不需要安装 CC Switch；只需要 Claude Code CLI，以及你选择的供应商配置。

## 使用便携版

从 GitHub Releases 下载 5.2 正式版 `Claude-Code-UI-5.2-portable.exe`，双击即可启动。便携版已经包含桌面界面和 Electron，不需要另外安装 Node.js。

首次运行若出现 Windows SmartScreen 提示，请先核对下载来源和 Release 页 SHA-256。当前社区构建没有商业代码签名；提示不等于已检测到病毒，也不要求必须上架 Microsoft Store，但不建议关闭 Defender 或 Smart App Control。

## 基本使用

1. 打开 Claude Code UI 5.2。
2. 点击左侧“新建项目”并选择项目目录；名称可留空，由应用根据本地项目信息自动识别。创建后点击项目右侧“+”或“新建第一段会话”开始对话。
3. 未选择项目时可在“未归类对话”区域新建独立会话；项目和会话标题旁的铅笔都可直接重命名。
4. 输入任务并按 Enter 发送；Shift + Enter 换行。
5. 使用输入台按钮切换模型、推理强度和权限模式。
6. 对话较长时，可使用右侧任务时间线查看每一阶段的主题并跳转定位。

模型选择“跟随 Claude Code 配置”时，不传入模型覆盖参数，由本机 Claude Code 配置决定实际模型；也可以选择 `sonnet`、`opus`、`haiku`、`fable`、`deepseek-v4-pro`、`deepseek-v4-flash`，或输入其他模型 ID。每次收到 Claude Code 的运行回显后，界面会用“实际”标记确认结果。

截图识别推荐选择国内的 `glm-4v-flash`。智谱官方将它标为免费的单图理解模型，但仍需要你自己的智谱账号 API Key，并受账号速率和平台规则限制；视觉模型先识别截图，再把识别结果交给当前会话模型继续处理。应用不会把截图上传到本项目服务器。

首次点击输入台的截图按钮时，应用会弹出“输入您的智谱 API Key”。密钥使用 Windows 凭据加密保存在本机，也可以在启动应用前设置 `ZHIPU_API_KEY` 环境变量；应用只直连智谱官方接口，不会发送到本项目服务器。Gemini 仍可作为手动输入的可选海外模型，但不是默认路径。

“推理强度”对应 Claude Code 的 effort 参数，不是网络下载速度。更高的强度通常会进行更多分析，也可能使用更多时间和 Token。

## 隐私

- Claude Code UI 只在本机启动 Claude Code CLI，不提供自己的云端中转服务。
- 会话历史与界面设置保存在当前 Windows 用户的应用数据目录。
- 发布包不包含开发者的 Claude 登录、API Key 或聊天历史；你输入的智谱 Key 只保存在自己的 Windows 用户数据中。
- 发送给模型的数据范围仍由你自己的 Claude Code、供应商与项目配置决定。

## 本地开发

需要 Node.js 22 或更高版本：

```powershell
npm install
npm start
```

类型检查：

```powershell
npm run typecheck
```

生成 Windows 便携版：

```powershell
npm run pack:win
```
